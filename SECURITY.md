# Security

Report vulnerabilities privately to `farshid.imanipour@gmail.com` rather than
in a public issue or Mumble channel. Include affected versions, reproduction
steps, and impact when possible. The maintainer will acknowledge the report,
investigate it, and coordinate remediation before public disclosure.

Mumble Share 0.1.1 is an unsigned stable release for this private server.
Verify the SHA-256 digest published on
the onboarding page before installing it.

Invitations expire after two minutes and carry only a random identifier and
PairDrop room code. Room codes are discovery aids, not passwords. PairDrop
still requires the receiver to approve the file. Never accept an unexpected
invitation or transfer.
