Privacy

Files are transferred between browsers using encrypted WebRTC. PairDrop uses this server for discovery and may use its TURN service as an encrypted relay when a direct connection is unavailable.

The service does not provide file storage and has no file database. WebSocket file fallback is disabled. Standard web access logs contain connection metadata such as time, IP address, and requested path; they do not contain transferred files.

Temporary public-room codes are short discovery codes, not passwords. Only accept transfers from the person you expect.

The plugin sends an invitation only after the user activates its sharing shortcut. It contains a random identifier, room code, and expiration time—not file contents, paths, or names. The source code is public.
