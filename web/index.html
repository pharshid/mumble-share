Mumble Share

Send large images and files to people in the Mumble server without uploading them for permanent storage.

Open file sharing Desktop integration

Use it now

  1. Open file sharing and create a temporary public room.
  2. Copy its room link into Mumble.
  3. Paste or select a file, then choose the recipient.

Normal images can still be pasted into Mumble with Ctrl+V. Use this page for files, videos, and large images such as 10 MB originals.

Desktop integration

The optional Windows x64 plugin opens one shared room and invites everyone currently in your Mumble channel. Ordinary Mumble image paste remains unchanged.

Version 0.1.1 fixes the “helper was not found” error from 0.1.0. Close Mumble and install this update over the old version.

  1. Close Mumble, run the installer, then start Mumble again.
  2. Open Mumble's plugin settings and check both Enable and KeyEvents for Mumble Share.
  3. Press Ctrl+Shift+V or Ctrl+Shift+F, then paste or choose the file once in PairDrop.
  4. Recipients approve the invitation and the actual transfer.
